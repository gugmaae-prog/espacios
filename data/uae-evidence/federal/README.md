# Selected federal historical census counts

`fcsc-census-selected-20261114.json` contains 56 emirate/year/metric observations from the Federal Competitiveness and Statistics Centre's *Emirates in Figures* tables. The [2009 edition, PDF page 30](https://fcsc.gov.ae/wp-content/uploads/2025/04/%D8%A7%D9%84%D8%A5%D9%85%D8%A7%D8%B1%D8%A7%D8%AA-%D8%A8%D8%A7%D9%84%D8%A3%D8%B1%D9%82%D8%A7%D9%85-2009.pdf) and [2007 edition, PDF page 23](https://fcsc.gov.ae/wp-content/uploads/2025/04/%D8%A7%D9%84%D8%A5%D9%85%D8%A7%D8%B1%D8%A7%D8%AA-%D8%A8%D8%A7%D9%84%D8%A3%D8%B1%D9%82%D8%A7%D9%85-2007.pdf) agree for the selected values. `fcsc-census-selected-source.json` records the PDF checksums, table values, official national totals, and exclusions. `build-fcsc-historical-census.mjs` validates every national total before writing the data and validation report.

The selected building-count years are 1975, 1980, 1985, 1995, and 2005. Housing-unit counts use 1985, 1995, and 2005. The [2006 edition](https://fcsc.gov.ae/wp-content/uploads/2025/04/%D8%A7%D9%84%D8%A5%D9%85%D8%A7%D8%B1%D8%A7%D8%AA-%D8%A8%D8%A7%D9%84%D8%A3%D8%B1%D9%82%D8%A7%D9%85-2006.pdf) conflicts with the later editions for some 2005 totals, and the oldest housing-unit year is labelled differently across editions; those disputed values and year labels are excluded. The API reports these discrepancies rather than silently merging them.

The read-only route `/map/api/uae-evidence/federal/historical-building-housing` supports `metric`, `year`, and `emirate` filters. It is historical census stock context. It does not establish current standing stock, available commercial spaces, project identities or coordinates, sale/rent observations, or forecasts. The 6,510-byte selected JSON snapshot was copied to private IDrive E2 and independently read back with exact SHA-256. The Worker serves a checksum-verified immutable bundled copy; the IDrive object is a verified replica and is not the runtime primary for this route while the shared auth Worker remains blocked by its R2 binding.
