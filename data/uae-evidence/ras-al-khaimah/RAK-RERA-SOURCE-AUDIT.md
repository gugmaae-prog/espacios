# RAK RERA project-list source audit

The [RAK Municipality Sanad off-plan list](https://sanad.mun.rak.ae/docs/en/rera-updated-developers-list) showed 81 numbered project and developer rows on 14 November 2026. The page does not establish a list observation date or stable project identifiers. A separately linked [2024 project-status PDF](https://mun.rak.ae/wp-content/uploads/2024/09/6-%D9%82%D8%A7%D8%A6%D9%85%D8%A9-%D8%A7%D9%84%D9%85%D8%B4%D8%A7%D8%B1%D9%8A%D8%B9-2024Sep.pdf) showed 45 rows on visual inspection, but its dated statuses cannot be treated as current.

The private HTML capture is retained outside Git and pinned by SHA-256 in the candidate audit. A reproducible exact-name check finds 34 one-to-one *candidates* among 89 accepted RAK map features. This is not an approved identity crosswalk: project names can be reused, renamed or scoped to different phases, and the source row number is only page order.

[RAK Municipality's copyright notice](https://mun.rak.ae/home/open-data/website/copyrights/) reserves rights and prohibits unauthorized reproduction. The [site terms](https://mun.rak.ae/terms-conditions/) do not grant a dataset redistribution licence. This audit therefore publishes only source references, checksums and aggregate review counts. It does not reproduce the official list, PDF, project names, developer values or status rows in Espacios.

The published RAK backend remains on separately approved sources. A project register can be added only with a clear reuse basis and reviewed identity, vintage and coordinate semantics.
