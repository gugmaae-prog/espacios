# Ajman official quarterly unit-sales aggregates

Source: [Real Estate Units Sales, Ajman Open Data](https://data.ajman.ae/explore/dataset/real-estate-units-sales/), published by the Department of Land and Real Estate Regulation. The source metadata reports a [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) licence and a last modification time of 2026-08-21T04:37:58.396000+00:00. This package attributes the source and retains its export, metadata and exact checksums.

The export contains 6,075 quarterly aggregate rows for 2019 Q1 through 2026 Q2. It reports 15,991 unit sales and AED 6,218,360,220.16 in total value across those rows, grouped under 239 distinct source project labels. These are aggregates at source project label, sector, district, unit type, rooms and quarter grain. They are **not** individual transaction records, 239 verified map projects, complete Ajman project coverage or a coordinate source.

`validation.json` records the source URL, licence, hashes, row count and limitations. `scripts/build-ajman-open-data.mjs --check` verifies the package against the full official export. The immutable compressed object is served through a separate, private IDrive E2 prefix and a strict one-key allowlist. `/map/api/uae-evidence` reports the source and limits; `/map/api/uae-evidence/ajman/projects` exposes source labels without canonical joins; `/map/api/uae-evidence/ajman/sales` pages the native aggregates.

The same verified export has **89 commercial unit-sale aggregate rows**: 64 labelled Office and 25 labelled Shop, across 22 distinct source project labels. Their reported counts sum to 346 sales (315 Office and 31 Shop), with AED 121,329,157 in reported value. `/map/api/uae-evidence/ajman/commercial-sales` exposes this subset with `unitType=Office|Shop`, year, quarter, exact project label and pagination filters. It retains the underlying source row index and checksum, and makes no claim about individual unit identity, current availability, asking price, rent, floor area, or map location. The separate municipal `/map/api/uae-evidence/ajman/rent-contracts?city=ajman&category=Commercial` route supplies commercial contract **counts**, not prices or available spaces; Manama and Masfoot have separate city routes.

The optional `view=map` on the commercial-sales API joins only the bilingual `Rashideya 1` and `Rashideya 2` district labels to their exact `AL RASHIDEYA 1` and `AL RASHIDEYA 2` names in the separately verified 2023 Ajman Municipality area-point source. Across 2019–2026 Q2, this represents 55 of 89 aggregate rows and 302 of 346 reported sales; for the complete 2025 calendar year, it represents nine of 12 aggregate rows and 77 of 80 reported sales. The other rows and counts remain in the source API. These are dated area reference points, not verified district centroids, project sites or sale-unit locations. The 2026 period is partial. See [the crosswalk review](../../../docs/verification/ajman-commercial-map-v58-20261111.md).

No name-only links to accepted V48 identities or map coordinates have been made. The existing 1,645-project map and 1,860-record V48 history remain separate from this Ajman source. A broader UAE catalogue and the missing original history and model bundles still require exact, licensed source recovery.

## Official development-project register

The [Real Estate Projects dataset](https://data.ajman.ae/explore/dataset/real-estate-projects/) is a separate CC BY 4.0 source from the same department. Its 3,457 rows represent 16 dated snapshots, covering 364 distinct source project IDs over time. The latest 2026-06-30 snapshot contains 298 IDs; 66 older IDs are absent from that snapshot, so their present status is not asserted. The source has no coordinate fields. Fifty-eight historical unit-count cells are nonnumeric, including three in the latest snapshot; those are returned as unknown. Thirty-five historical rows have an anomalous city field. `projects-validation.json` records these bounds and both raw and compressed checksums.

`/map/api/uae-evidence/ajman/register` searches the latest source snapshot by default and can list the latest known row for all 364 source IDs with `scope=all`. `/map/api/uae-evidence/ajman/register/{sourceProjectId}` returns that ID's dated source history. The public API omits escrow account numbers and does not manufacture V48 identities, current status for absent IDs, or map pins.

The [Completed Real Estate Development Projects dataset](https://data.ajman.ae/explore/dataset/completed-real-estate-projects/) has 496 dated rows and 191 source project IDs. Its IDs and dated completed statuses exactly match rows already in the development-project register, so it adds no new project identities. It must not be added to the 364-ID register or the V48 map count.

## New-building permissions by broad use

The municipality's [Licenses Issued for New Buildings by Number of Buildings](https://data.ajman.ae/explore/dataset/licenses-issued-for-new-buildings-by-number-of-buildings/) is a separate CC BY 4.0 dataset. Two independent full exports matched exactly. The captured 23 September 2026 vintage has 284 month/use rows for 2015–June 2026. Eight 2023 month/use pairs contain conflicting duplicate values, so both values in each pair are withheld. The remaining 268 rows include complete 2024 and 2025 series; 2026 is partial through June.

`/map/api/uae-evidence/ajman/new-building-use` exposes the verified rows, with year, month, and broad residential or non-residential use filters. The 2025 non-residential rows sum to **228 buildings on new-building permissions**. Non-residential includes uses beyond commercial; this is not a count of commercial spaces, completed buildings, transactions, or current inventory. The source is distinct from the Ajman building-type permit series and must not be added to it. `new-building-use-capture.json`, `new-building-use-validation.json`, the metadata, and the immutable compressed export retain exact provenance and checksums. The commercial page labels this as historical permit evidence.

## Tentative and final unit registrations

The separate [Real Estate Units Registration dataset](https://data.ajman.ae/explore/dataset/real-estate-units-registration/) is CC BY 4.0 and contains 5,124 quarterly aggregate rows from 2019 Q1 through 2026 Q2 under 335 source project labels. Its two measures are tentative registration certificates and final title deeds. The captured rows sum to 14,242 certificates and 7,852 title deeds; these are separate stages and must not be added into a unique-unit or sale count. The source does not identify individual transactions.

`registration-validation.json` records the exact source vintage, metadata, hashes, row count, distinct labels, and separate stage totals. `scripts/build-ajman-unit-registration.mjs --check` revalidates the full export. The compressed source is in the private IDrive E2 allowlist and was independently read back after upload. `/map/api/uae-evidence/ajman/registrations` pages source rows and supports year, quarter, exact project-label, and registration-stage filters. It reports no canonical V48 match or coordinate.

## Mixed unit dispositions

The [Real Estate Units Transactions dataset](https://data.ajman.ae/explore/dataset/real-estate-units-transactions/) is CC BY 4.0 and contains 6,299 aggregate rows under 249 source project labels. The publisher description includes unit dispositions, mortgage registrations and mortgage-value changes, but the export does not include a transaction-type field. This is not a sale-only count and overlaps the unit-sales dataset; its 18,057 reported counts must not be added to the 15,991 sale count. No canonical project join or coordinate is asserted.

The captured export has 318 rows with unknown year and quarter and 4,594 rows with unknown monetary values. These remain null. Reported monetary values occur only through 2021 Q4 in this export, so the known-value sum is incomplete and must not be treated as later-period zero value. One duplicate dimension tuple is preserved as separate source rows. The 2021 Q2 and 2025 Q4 quarters are absent from the dated rows; absence is not zero activity. `transactions-validation.json` records the source vintage, metadata, exact hashes, counts, and limits. `scripts/build-ajman-unit-transactions.mjs --check` verifies the compressed source against its independent readback.

`/map/api/uae-evidence/ajman/dispositions` serves a paged, read-only view with exact source labels and known/unknown filters. Its checksum-verified immutable Worker asset is separate from the private IDrive objects above; the API reports its actual storage origin. Raw asset paths remain inaccessible.

## Unit mortgage aggregates

The [Real Estate Units Mortgage dataset](https://data.ajman.ae/explore/dataset/real-estate-units-mortgage/) separately reports 651 quarterly project-label, district, unit-type and room-count aggregates from 2019 Q1 to 2026 Q2 under CC BY 4.0. Two independent publisher exports matched all 386,928 bytes. They contain 155 distinct project labels, 1,244 reported mortgage actions, and AED 646,133,934 in reported value. The publisher includes mortgage registrations and mortgage-value modifications, so these are not necessarily unique loans. The source overlaps the mixed unit-dispositions dataset and must not be added to it. The 2021 Q2 period is absent; five rows have unknown room counts.

`real-estate-units-mortgage-validation.json` records the source vintage, exact hashes, quality counts and limits. `scripts/build-ajman-unit-mortgages.mjs --check` verifies the immutable compressed source against the independently read publisher copy. `/map/api/uae-evidence/ajman/unit-mortgages` pages source-labelled rows and supports year, quarter, project-label and district filters. It provides no canonical V48 identity, project-site coordinate, individual mortgage, sale price or all-UAE denominator.

## Project management appointments

The [Management Companies for Real Estate Development Projects dataset](https://data.ajman.ae/explore/dataset/management-companies-for-real-estate-development-projects/) is a separate [CC BY 4.0](https://data.ajman.ae/terms/terms-and-conditions.pdf) Ajman source. Its 451 annual rows cover 153 distinct official project IDs: 149 appointments each in 2024 and 2025, and 153 in 2026. All 153 IDs exist in the official Ajman project register. Thirteen office IDs appear, and three projects have a changed office ID across the reported years. The management company is neither the developer nor the owner.

`management-companies-20260609.json.gz` stores the reviewed 9 June 2026 source vintage. `management-capture.json` records the paged API capture and matching independent readback checksum. `management-source-metadata.json` retains licence and schema metadata without republishing the portal's descriptive text. `management-validation.json` records exact hashes and quality checks; `scripts/build-ajman-management.mjs --check` reproduces them. One official register English-name field contains Arabic text for source ID 415; the exact numeric ID is retained without inventing an English-name match.

`/map/api/uae-evidence/ajman/management` serves the checksum-verified snapshot with `scope=latest` by default and supports reported year, source project ID, and text filters. The 2026 rows are the latest reported appointments, not proof of today's management status. The API publishes no V48 canonical ID or map coordinate, and raw snapshot bytes have no public route.

## Dated area reference points

The Ajman Municipality & Planning Department's [Ajman area dataset](https://data.ajman.ae/explore/dataset/ajman-area/) publishes 20 named point references under CC BY 4.0. Its last reported source modification was 3 October 2023. The two independent ordered API reads of all 20 rows matched exactly; `area-reference-capture.json` and `area-reference-validation.json` record the source and compressed SHA-256 checksums. `scripts/build-ajman-area-reference.mjs --check` validates the names and coordinates.

`/map/api/uae-evidence/ajman/areas` serves these as labelled **area reference points**. The dataset does not state that they are project sites, cadastral boundaries, or verified district centroids. No source project ID is joined to a point and the map's project-pin population is unchanged.
