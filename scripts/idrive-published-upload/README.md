# Published UAE evidence IDrive E2 replica

This copy set has 37 immutable objects (4,207,862 stored bytes) in `espacios-store-a` under `espacios-map/uae-evidence/published/20261114/`. The [plan](../../data/uae-evidence/idrive-e2-published-replica-plan-20261114.json) pins each repository source file, validation report, source ID, content type, byte length, SHA-256, and key. The [attestation](../../data/uae-evidence/idrive-e2-published-replica-readback-20261114.json) records an immediate read after each upload and a separate signed GET of every object. Private preview access and receipts stay outside Git in `work/idrive-replica/published-20261114/`.

The set covers the remaining 34 published evidence projections in the seven-emirate coverage inventory, including the [selected SCAD stock facts](../../data/uae-evidence/abu-dhabi/scad-stock-selected-20261114.json) and two Abu Dhabi developer-geometry files. It includes selected numerical facts and previously published projections only. It excludes source article/page bodies, listing photos, and the unpublished ADREC transaction-level candidate. SCAD attribution and the [open-data policy](https://www.scad.gov.ae/documents/d/guest/scad-open-data-policy) remain attached to the selected stock facts.

`transfer.mjs prepare` validates every planned local and raw checksum against its source report. `stage` creates an inactive, short-lived upload-only version of `espacios-ai-router` with inherited E2 secrets and an exact object allowlist. `upload` conditionally writes and immediately reads each object. `verify` makes a separate signed GET, checking content type, byte length and SHA-256. `attest` reconciles all receipts and confirms production routing stayed unchanged. `verify-attestation` checks the public attestation and repository files without credentials. `verify-uae-idrive-storage.mjs` reconciles this copy with the six-object current-evidence and 155-object Dubai Municipality replicas.

The map APIs continue serving their existing Worker and accepted V48 evidence sources. IDrive is a **dated verified replica** for these published projections, not their runtime primary or a continuous whole-store health check. The accepted V48 archive has its separate IDrive primary. All 38 current published projections have a verified replica, but they are not a complete UAE project census, complete original authority archives, verified unit locations, current listing inventory, or complete sale/rent history.
