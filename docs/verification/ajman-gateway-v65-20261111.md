# Ajman Gateway identity review · v65

The accepted V48 map contains a current **Gateway Porto Al Zorah** card and a separate archived **The Gateway Porto by Al Zorah** card. Both carry the same approximate Al Zorah community-centre coordinate and Q4 2026 handover label. These catalogue fields alone do not establish a surveyed project site or a distinct development.

The retained [Ajman project-register snapshot](https://data.ajman.ae/explore/dataset/real-estate-projects/) has official source project ID **471**, name **GATEWAY**, developer Al Zorah Development, Zorah district, and **157** reported units at 2026-06-30. The [developer project page](https://www.alzorahcity.com/gateway-porto-al-zorah) and [26 October 2023 developer announcement](https://www.alzorahcity.com/assets/pdf/Al-Zorah-City-introduces-its-latest-luxury-marina-front-project-Gateway.pdf) identify Gateway at Porto Al Zorah as a 157-apartment development. The official row, developer name, district and unit count support a reviewed one-to-one identity with the current V48 card. The archived card is recorded only as another catalogue ID for that same official source project. Its corrupted developer field is not used as identity evidence.

The crosswalk verifier pins the raw Ajman snapshot and accepted V48 catalogue checksums, checks source and map fields, confirms the official ID is unique in the latest snapshot, and checks the alias is an archived separate card. The API exposes the canonical ID and the archived alias separately at `/map/api/uae-evidence/ajman/register/471`. The official source ID counts once; the alias does not increase the 298 latest official source IDs or accepted 1,645 V48 project records. No status, handover, price, coordinates, or timeline is copied from one source to another.

The Ajman register itself remains a verified private IDrive E2 object with an immutable recovery fallback. This release changes only its reviewed identity crosswalk and coverage metadata. It does not upload the new Dubai Ejari snapshot to IDrive or make the UAE inventory complete.
