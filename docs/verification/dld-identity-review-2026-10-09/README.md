## Reproduction

With the retained private captures available:

```sh
python3 tests/dld-identity-review.py
python3 scripts/review-dld-identity-pass38.py
```

The script validates every source checksum before generating this review and requires the V37 baseline. Tests cover fractional/large IDs, sparse candidates, duplicate/conflicting IDs, wrong buildings, land, gifts, future dates and invalid price formulas. It never invokes enrichment, changes the catalogue or deploys a Worker.
