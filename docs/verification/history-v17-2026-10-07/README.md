# V17 production release verification

V17 is published at the immutable root recorded in `publication.json`. The
receipts capture publication, Worker traffic, production API and Supabase
control-plane state, browser palette review, and temporary publisher cleanup.

The release preserves all 1,860 catalogue records. It adds public ADREC
registration and point-in-time progress evidence for a subset of projects; it
does not add prices or rents. The 42,780-requirement ledger still has 39,690
unresolved requirements (92.78%), complete lifetime sale/rent histories are not
established, and validated annual forecasts through 2080 remain at zero.

The map's previously deployed Espacios slate/teal selection palette remains in
place. The light and dark themes were checked; the user's original dark theme
was restored after the visual check. The temporary history publisher and its
local credential files were removed after publication.
