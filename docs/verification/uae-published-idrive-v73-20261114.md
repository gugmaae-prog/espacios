# Seven-emirate published-evidence IDrive replica — 14 November 2026

The current coverage inventory lists 38 published evidence projections across Abu Dhabi, Ajman, Dubai, Fujairah, Ras Al Khaimah, Sharjah and Umm Al Quwain. This release copied the remaining 34 source projections in 37 files (4,207,862 stored bytes) to private IDrive E2. Each upload passed an immediate readback and a separate signed GET with matching content type, byte length and SHA-256. See the [exact copy plan](../../data/uae-evidence/idrive-e2-published-replica-plan-20261114.json) and [readback attestation](../../data/uae-evidence/idrive-e2-published-replica-readback-20261114.json).

Together with the previously verified six current-evidence objects and 155 Dubai Municipality objects, the dated readback attestations now cover **38 of 38 published projections** in coverage version `20261114-uae-evidence-coverage-v42`. Those three copy sets contain 198 objects and 108,324,202 stored bytes. The accepted V48 archive is a separate IDrive-primary collection with immutable recovery fallback. `/map/api/uae-evidence/storage` maps every published source ID to its replica attestation and readback time, and `/map/system` links to that inventory. Source APIs retain their existing runtime storage and evidence classes.

The new Abu Dhabi census file contains only the eight rounded, attributed stock totals already served by the map. It does not copy SCAD web pages or graphics. The unpublished ADREC transaction-level candidate, listing photos, and source article bodies are excluded. The [SCAD open-data policy](https://www.scad.gov.ae/documents/d/guest/scad-open-data-policy) requires attribution; the [census source](https://census.scad.gov.ae/home/) identifies the revised 2023 figures.

The attestation proves exact private reads at its stated time, not current whole-store availability. A complete replica of **published projections** does not establish a complete UAE project denominator, missing coordinates, registered transaction coverage, current commercial availability, or forecast validity. R2 remains disabled and Data Room remains restricted.
