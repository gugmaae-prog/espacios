# Dubai Office/Shop subtype sales, 2026 partial

The licensed Dubai Real Estate Data copy of Dubai Land Department registrations was captured on 2 November 2026. Its Parquet SHA-256 is `8294c3dd83dde2e16e64eaf1ef155a1ad14ec16b6b39384561777afb8425417e`. The secondary dataset is [CC BY 4.0](https://huggingface.co/datasets/dubairealestatedata/dubai-real-estate-sales-transactions/blob/main/LICENSE.md); [DLD's open-data page](https://dubailand.gov.ae/en/open-data/real-estate-data/) describes the original source. The source is a dated copy, not a live DLD feed.

The new endpoint selects sale registrations dated 1 January–31 October 2026 where `property_type_label = Unit` and `property_sub_type` is `Office` or `Shop`. Transaction IDs are unique. It contains **5,452 rows**: **1,133** still have source usage `Commercial`, while **4,319** have the conflicting source usage `Residential`. The shift begins on 9–10 February. The source `usageLabel` is retained on every record; the full set is labelled **subtype-based candidate commercial evidence pending primary-source verification**. This is not a complete 2026 year, all UAE, current availability, asking rent, or a unit-location dataset.

Counts include all rows. The 4,982 rows with `quality_flags = 0` alone contribute to price sums and medians. The API separates the new slice from the confirmed `Commercial` usage slice ending 9 February and from the 2006–2025 historical Office/Shop dataset. The commercial page offers a separate 2026 map action. Its circles use only four reviewed OpenStreetMap area references that exactly match DLD area names; unmatched rows stay in the API. No circle is a unit or building coordinate.

Reproduce with `python3 scripts/build-dubai-commercial-sales-subtype-2026.py` from the pinned Parquet in `work/dubai-commercial-capture/`. CI can run `--check` against the committed compressed bytes and validation report without the private build workspace. `node --test tests/dubai-commercial-sales.test.mjs tests/rgestate-commercial.test.mjs tests/uae-coverage.test.mjs` checks the source counts, record labels, area map boundary, and compiled Worker routes.
